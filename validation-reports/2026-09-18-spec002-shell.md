programs adopt. Spec: `specs/002-shell.md`.

`shell` (section lifecycle, options, window skeleton, busy, perform, banners,
Appearance and About sections, restart), `cmd/fynedesygn-gallery` rewritten
onto it with a Shell demo section and an About section, documentation updates.

## Phase 3: tests

`go test -race ./...` on Linux, no display: all packages pass.

| Package | Coverage |

The uncovered shell code is `New` and `Run` (a real app and window), the
popup timers, and `Restart`; the gallery's is `main` and the job's goroutine
body.

Shell tests exercise every acceptance criterion headlessly, with a Fyne test
window where the swap and popup paths need a canvas: detach ordering, inline
perform (canary 11), refusal while working including `AlsoWorking`, busy as a
count, one banner at a time with a stale-timer guard, palette tints, silent

on a real goroutine, one-run scheme override not reaching the store,
Appearance and About sections rendering with their content, `Invalidate`
building only on screen, unknown start section, gating.

`go vet`, `gofmt`: clean.

## Phase 4: code quality

- golangci-lint v2.12.2: 0 issues after two gofmt fixes.
- The gallery's own shell (nav list, content pane, appearance plumbing) is
  deleted; it is now `shell.Run(options(...))`.
- `Busy` guards its counters with a mutex because it is documented as safe
  from any goroutine and `Working()` is read from builders; the UI-thread
  fields (popups, sequence numbers) are touched only inside `fyne.Do`.
- Known duplication: `Appearance` picker code in `shell/appearance.go` and
  the gallery's former picker; the gallery copy is deleted, so one remains.

## Phase 5: security review

- `govulncheck -mode binary` on the built gallery: no vulnerabilities.
- `Restart` executes `os.Executable()` with the process's own arguments and
  environment, on Unix via `syscall.Exec` and on Windows via `exec.Command`
  with an argument slice, never a shell string. Both carry a `nolint:gosec`
  with the reason.
- No credentials, no network. Secrets grep: clean.
